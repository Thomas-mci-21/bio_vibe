# 项目总览：异星适应者

## 一、项目定位

“异星适应者”是一门 2 小时左右的跨学科体验课，融合高中生物的“适应与进化”内容，以及 Vibe Coding 的人机协作实践。学生抽取一个极端外星环境，先从生物学角度设计适应策略，再用自然语言指挥 AI 生成一个可交互网页。

这个项目不是为了教学生手写 HTML/CSS，而是让他们体验：如何把一个模糊想法变成清晰描述，如何向 AI 提出修改意见，如何判断 AI 产出的内容是否符合科学逻辑和审美目标。

## 二、适合对象

- 高中生物课程：适应性、自然选择、结构与功能相适应
- AI 素养课：提示词表达、反馈迭代、人机协作
- 创客/STEM 活动：跨学科项目制学习
- 校园开放日或课程宣传活动

## 三、学习目标

### 生物学目标

- 解释环境压力如何影响生物形态与行为。
- 用“结构服务功能”的方式设计生物适应特征。
- 能为一个虚构生物给出相对自洽的生存逻辑。

### AI 协作目标

- 用自然语言描述网页、视觉、交互和修改需求。
- 通过多轮反馈优化 AI 产出，而不是接受第一版。
- 理解“AI 生成结果需要人来判断和指导”。

### 表达与展示目标

- 完成一个可打开、可演示的 HTML 图鉴。
- 用 30 秒说明生物名称、星球环境、核心适应特征。
- 在同伴提问中解释设计理由。

## 四、最终产出

每组需要提交：

- 一个最终版 HTML 文件。
- 一个包含至少 3 个适应特征标注的异星生物图鉴。
- 一个“生存挑战”按钮或交互演示。
- 一段 30 秒作品介绍。

## 五、项目时间轴

| 阶段 | 时间 | 核心任务 |
| --- | --- | --- |
| 导入 | 0-12 分钟 | 生物适应破冰、Vibe Coding demo、发布任务 |
| 构思 | 12-30 分钟 | 抽星球、读策略卡、画草图、填形态模板 |
| 第一次 Vibe | 30-70 分钟 | 在环境基座中加入生物和标注 |
| 生存挑战 | 70-90 分钟 | 添加环境变化与适应演示 |
| 测试收尾 | 90-100 分钟 | 保存、测试、准备展示 |
| 异星博览会 | 100-120 分钟 | 展示、提问、投票和颁奖 |

## 六、课程设计判断

环境基座不追求完全电影级，而是承担三个功能：

- 给学生一个有氛围的舞台，避免白底空页面过于简陋。
- 用环境视觉元素提醒学生具体的生存压力。
- 保留足够空白，让学生的生物和交互成为主角。

课堂真正的高光不只是“最终网页好看”，而是学生经历了从初版粗糙、不断修改，到能解释生物适应逻辑的过程。
