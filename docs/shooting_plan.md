# 拍摄宣传方案

## 一、拍摄目标

这堂课适合拍成：

- 3-5 分钟课程宣传片。
- 30-60 秒短视频若干。
- 图文推文素材。
- 学生作品集锦。

宣传片主线建议：

> 学生从一个陌生星球出发，用 AI 和自己的生物学想象力，创造出能活下来的异星生命。

## 二、设备建议

- 主机位：三脚架固定，拍教师讲解和全班氛围。
- 游走机位：手机云台或手持相机，拍学生讨论、屏幕、草图。
- 收音：教师佩戴领夹麦。
- 屏幕录制：提前选 2-3 组录制 AI 对话和网页迭代。

## 四、采访问题

学生采访：

- 你抽到的是哪个星球？它最大的生存困难是什么？
- 你的生物最重要的适应特征是什么？
- AI 第一版做出来时你是什么感觉？
- 你改了几轮？最关键的一次修改是什么？
- 这节课和平时生物课有什么不一样？

教师采访：

- 为什么用 Vibe Coding 教生物适应？
- 为什么不直接教代码？
- 这堂课最想让学生带走什么能力？
- 学生作品里最值得被看见的不是哪里“好看”，而是什么？
