# 学生任务卡：演化设计局

欢迎来到演化设计局。今天你不是普通学生，而是一名异星生物设计师。你会抽到一个陌生星球，并设计一种可以在这里活下来的生物。

你的工具不是画笔，也不是代码编辑器，而是 AI。你要用自然语言告诉 AI：你的生物长什么样，为什么这样长，观众点击哪里会看到解释，环境变化时它如何活下来。

## 任务目标

制作一个单页 HTML 交互图鉴，展示你的异星生物。

你的页面至少包含：

- 生物的视觉形象。
- 3 个以上可点击适应特征标注。
- 1 个“生存挑战”演示按钮。
- 简短的生物名称、星球名称和生存说明。

## 五个星球

### A 风吼岩

终年强风，地表多岩石，光线微弱，地下有地热裂缝。

核心问题：

- 如何不被风吹走？
- 如何利用地热或弱光获取能量？
- 如何在岩石地表移动？

### B 糖浆海

低重力环境，海洋像浓稠糖浆，营养颗粒悬浮在液体中。

核心问题：

- 如何在粘稠液体中移动？
- 如何滤取食物？
- 如何保持方向和平衡？

### C 冰火轮

昼夜温差巨大，白昼强紫外，夜晚极寒。

核心问题：

- 如何抵抗强紫外？
- 如何面对极热与极寒？
- 如何在短暂温和期快速活动？

### D 浮空林

稠密大气，弱光，植物状生命漂浮在天空形成空中森林。

核心问题：

- 如何长期滞空？
- 如何在弱光下获取能量？
- 如何在空中森林间移动？

### E 流沙塔

地表是松软流沙，只有稀疏的巨柱植物形成孤立生态岛。

核心问题：

- 如何不陷入流沙？
- 如何利用巨柱植物？
- 如何在生态岛之间迁移？

## 形态生成模板

先把下面模板填完，再发给 AI：

```text
我的生物生活在：__________ 星球。
它整体像一个：__________，大小约：__________。
它最显眼的身体结构是：__________。
这个结构的功能是：__________。
它还有两个辅助适应特征：__________、__________。
它的主要颜色是：__________。
它移动的方式是：__________。
当遇到生存挑战时，它会：__________。
```

## 给 AI 的第一轮指令

```text
我正在做一个异星生物图鉴网页。我会把一个 HTML 环境基座发给你。
请在 id 为 creature-stage 的区域里，用 HTML/CSS 画出我描述的异星生物。
不要删除原来的环境背景。
请加入 3 个可点击标注，点击后显示这个身体结构如何帮助它适应环境。
这是我的生物设定：
（粘贴你的形态生成模板）
```

## 迭代原则

- 第一版不好看很正常。
- 不要只说“改好看点”，要说清楚哪里要改。
- 每次给 AI 2-3 条具体修改意见。
- 每个奇怪结构都要能解释它的生存作用。

## 展示时要回答

- 它叫什么？
- 它生活在哪个星球？
- 它最重要的适应特征是什么？
- 如果环境突然变化，它如何活下来？
