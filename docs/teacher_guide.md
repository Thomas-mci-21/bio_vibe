# 教师引导手册：异星适应者

## 一、课前准备

### 技术准备

- 确认 AI 工具可用。
- 将 `environments/` 中五个 HTML 基座提前发给学生或放在共享文件夹。
- 准备一个简单 demo：让 AI 生成一个点击变色的 HTML 小页面。
- 测试浏览器打开本地 HTML 文件是否正常。
- 如果要公开展示，提前开启 GitHub Pages。

### 物料准备

- 星球档案卡。
- 设计策略卡。
- 学生任务卡。
- 白纸、彩笔。
- U 盘或在线提交方式。

### 教室布置

- 2-3 人一组。
- 每组至少一台联网电脑。
- 教师电脑连接投影。
- 预留拍摄人员走动空间。

## 二、课堂流程

### 0. 入场抽卡

学生入场后抽取星球卡，按星球或随机分组落座。桌上放好星球卡、策略卡、白纸和彩笔。

### 1. 导入与概念引爆（0-12 分钟）

破冰提问：

> 如果把一种普通动物放到撒哈拉沙漠中心，经过很长时间，它的后代可能会出现什么特征？

引导学生说出储水、夜行、厚皮、耐热、节能等关键词。

Vibe Coding 说明：

> 今天你们不是来学代码的。你们是异星生物设计公司的创意总监。AI 是你的程序员，你用自然语言告诉它要什么，它给你网页。你不满意，就继续提修改意见，直到它接近你的想法。

快速 demo：

1. 投屏打开 AI。
2. 输入：“请生成一个 HTML 页面，背景是浅蓝色，中间有一个红色圆形，点击它后弹出一句话。”
3. 保存为 `.html` 并拖入浏览器。
4. 强调：课堂重点不是懂代码，而是会描述、会判断、会修改。

### 2. 生物构思与草图（12-30 分钟）

教师指令：

> 先不要打开 AI。先看星球卡，圈出一个你最想解决的生存问题。然后选 1-2 个设计策略，最后用模板写出你的生物设定。

学生完成：

- 核心生存问题。
- 设计策略。
- 形态生成模板。
- 纸上草图和 3 个适应特征标注。

教师巡回提问：

- 这个结构解决什么问题？
- 如果风暴、极寒、流沙或弱光突然出现，它怎么办？
- 观众最应该点击它身体的哪个部位？

### 3. 第一次 Vibe（30-70 分钟）

教师指令：

> 现在打开 AI。把你的星球 HTML 基座代码发给 AI，再把生物设定发给 AI。目标不是一次成功，而是先让它生出来。第一版丑是正常的，丑才有迭代空间。

常见学生问题与回应：

| 学生说 | 教师回应 |
| --- | --- |
| 我不知道怎么开头 | 把你刚刚跟同学解释的话原样发给 AI |
| 它画得好丑 | 很好，现在你是艺术总监，告诉它哪里不对、怎么改 |
| 它听不懂 | 换成更具体的身体部位、颜色、位置和动作 |
| 标注做不出来 | 告诉 AI：点击某个部位时，旁边弹出说明文字 |
| 我怕改坏 | 保存一个 v1，再继续改 v2 |

中段提醒：

> 现在所有人保存第一版，命名为 `v1.html`。不要覆盖它。后面你会需要展示前后对比。

### 4. 加入生存挑战（70-90 分钟）

教师说明：

> 一个真正的适应特征，必须经得起环境考验。现在给网页加入一个“生存挑战”按钮，让观众点击后看到环境变化，以及你的生物如何应对。

挑战示例：

- 风吼岩：超级风暴。
- 糖浆海：营养颗粒突然迁移。
- 冰火轮：极寒之夜降临。
- 浮空林：天空湍流。
- 流沙塔：流沙下陷。

### 5. 测试与准备展示（90-100 分钟）

学生完成：

- 保存最终版 `final.html`。
- 在浏览器里测试所有按钮。
- 准备 30 秒介绍。

### 6. 异星博览会（100-120 分钟）

每组 3 分钟：

- 1 分钟介绍星球和生物。
- 1 分钟演示网页交互。
- 1 分钟回答同学提问。

奖项建议：

- 最佳适应逻辑奖。
- 最炫视觉设计奖。
- 最会沟通奖。

## 三、教师原则

- 不替学生写完整提示词。
- 用问题帮助学生把想法说清楚。
- 评价重点是适应逻辑，不只是视觉效果。
- 鼓励保存多个版本，让迭代过程可见。
- 对“丑”的第一版保持欢迎，它往往是最好的宣传素材。

## 四、应急方案

| 风险 | 应对 |
| --- | --- |
| 网络断开 | 继续纸上设计，教师电脑集中演示，课后补做数字版 |
| AI 工具不可用 | 使用已经生成的环境基座讲解，改为生物设计与口头展示 |
| 某组进度落后 | 缩小目标：一个生物、两个标注、一个简单按钮 |
| 某组太快 | 加高级挑战：成功/失败两种环境结果 |
| 学生陷入审美纠结 | 提醒回到“结构如何帮助它活下来” |
