# Vibe Coding 工作流

## 1. 先描述，不求完美

学生第一轮不需要写复杂提示词，只要把自己的设定讲清楚。

```text
请在这个 HTML 的 creature-stage 区域里加入我的异星生物。
它生活在（星球名），整体像（形态），有（关键结构）。
这个结构用于（适应功能）。
请用 CSS 图形表现，不要引用外部图片。
```

## 2. 每轮只改 2-3 件事

不推荐：

```text
不好看，改一下。
```

推荐：

```text
请做三处修改：
1. 把身体颜色改成半透明蓝绿色。
2. 把头顶伞膜变大，并加发光斑点。
3. 让触手更细更长，像漂浮在空气中。
```

## 3. 标注交互指令

```text
请给这个生物加入 3 个可点击标注：
1. 点击头顶伞膜，显示它如何收集弱光。
2. 点击腹部气囊，显示它如何保持漂浮。
3. 点击触手，显示它如何抓住空中植物。
标注文字要简短，点击后在右侧信息框显示。
```

## 4. 生存挑战指令

```text
请加入一个“生存挑战”按钮。
点击后，环境进入（风暴/极寒/流沙下陷/天空湍流）状态。
让背景出现明显变化，同时让生物触发适应动作。
例如：收缩、发光、展开伞膜、伸出锚爪或进入休眠。
```

## 5. 保存版本

建议学生保存：

- `v1.html`：第一版，不管好坏。
- `v2.html`：加入标注后。
- `final.html`：加入生存挑战并测试后。

展示时可以用 v1 与 final 对比，说明自己如何指挥 AI 迭代。
