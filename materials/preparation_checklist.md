# 物料准备清单

## 一、硬件

| 物品 | 数量 | 用途 |
| --- | --- | --- |
| 联网电脑 | 每组 1 台 | 使用 AI 和打开 HTML |
| 教师电脑 | 1 台 | 投屏 demo 与展示 |
| 投影或大屏 | 1 台 | 讲解和博览会展示 |
| U 盘或共享文件夹 | 每组 1 个或 1 个共享入口 | 收集最终作品 |
| 手机或相机 | 2 台 | 主机位与游走机位 |
| 领夹麦 | 1 个 | 教师讲解收音 |
| 三脚架 | 1 个 | 固定全景 |

## 二、软件与文件

| 项目 | 准备方式 |
| --- | --- |
| AI 工具 | 提前测试登录和生成代码是否可用 |
| 浏览器 | Chrome、Edge 或 Firefox 均可 |
| 星球基座 | 下载 `environments/` 五个 HTML |
| 课堂 demo | 准备一个简单点击交互 HTML |
| 屏幕录制工具 | 选 2-3 组提前安装或测试 |

## 三、打印材料

| 材料 | 数量 |
| --- | --- |
| 学生任务卡 | 每组 1 份 |
| 设计策略卡 | 每组 1 份 |
| 星球抽签卡 | 五种星球各 2-3 张 |
| 评价/投票贴纸 | 每人 2-3 张，可选 |

## 四、文具

- 白纸。
- 彩笔或马克笔。
- 便签纸。
- 抽签信封或抽签筒。

## 五、课前检查

- 所有 HTML 文件可双击打开。
- AI 可以生成和修改 HTML/CSS。
- 投影能清楚显示代码和网页。
- 学生提交路径已经确定。
- 拍摄人员知道关键镜头时间点。

## 六、备用方案

| 问题 | 备用做法 |
| --- | --- |
| 网络断开 | 改为纸上设计和教师统一演示 |
| AI 无法使用 | 用教师电脑集中生成 1-2 个样例 |
| 学生电脑不足 | 两组共用一台电脑，保留纸上设计任务 |
| 时间不足 | 取消完整展示，改为每组 60 秒快速博览 |
