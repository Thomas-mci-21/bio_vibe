# 设计策略卡

使用方式：

1. 找到你抽到的星球。
2. 圈出一个核心生存挑战。
3. 选择 1-2 个设计策略。
4. 用形态模板写出你的生物设定。

## A 风吼岩

| 生存挑战 | 设计方向 |
| --- | --- |
| 不被强风吹走 | 锚定结构、低矮身体、吸盘、钩爪 |
| 弱光与地热 | 热感应、地热共生菌、化学合成 |
| 岩石地表移动 | 钻探、攀附、贴地爬行、利用风滑翔 |

| 策略 | 关键词 | 地球参照 |
| --- | --- | --- |
| 地锚型 | 钩爪、根状固定器、吸盘 | 藤壶、海星 |
| 流线型 | 低矮、硬壳、风阻小 | 沙漠甲虫、企鹅 |
| 潜地型 | 钻头、洞穴、感热触须 | 鼹鼠、沙蚕 |
| 风能型 | 风帆、滑翔膜、风向感受器 | 信天翁、蒲公英 |
